Información del Sistema

¿Qué es este sistema?

Este sistema utiliza Aprendizaje No Supervisado (K-Means Clustering) para agrupar vuelos según patrones similares de retrasos, ayudando a las aerolíneas a identificar problemas operacionales y tomar decisiones informadas.

¿Cómo ayuda esto a una aerolínea?

1. Identificación de Patrones

El sistema agrupa automáticamente vuelos con características similares, permitiendo identificar patrones que no son evidentes a simple vista. Por ejemplo, puede detectar que ciertas rutas o horarios tienen consistentemente más retrasos.

2. Optimización de Recursos

Al conocer qué vuelos tienen mayor probabilidad de retraso, la aerolínea puede asignar recursos adicionales (personal, equipos, puertas) de manera proactiva, reduciendo el impacto de los retrasos.

3. Reducción de Costos

Los retrasos generan costos significativos: compensaciones a pasajeros, reasignación de tripulaciones, mantenimiento adicional de aviones, etc. Identificar y prevenir retrasos reduce estos costos operativos.

4. Mejora de Satisfacción del Cliente

Vuelos más puntuales significan pasajeros más satisfechos, lo que se traduce en mejores reseñas, mayor fidelidad y aumento en las ventas.

5. Toma de Decisiones Basada en Datos

En lugar de decisiones basadas en intuición, el sistema proporciona evidencia clara sobre qué rutas, horarios o condiciones requieren atención prioritaria.

6. Mejora Continua

Al agregar nuevos datos periódicamente, el modelo se reentrena automáticamente, adaptándose a cambios en las operaciones y manteniendo las recomendaciones actualizadas.

¿Cómo funciona el sistema?

Paso 1: Entrenamiento Inicial

Entrene el modelo en su computadora con su dataset inicial (ej: 10,000 vuelos). El sistema analiza los datos y crea grupos (clusters) de vuelos similares basándose en:

  • Retrasos de salida y llegada
  • Retrasos por clima
  • Duración del vuelo
  • Hora de salida
  • Día de la semana
  • Rutas (origen-destino)

Paso 2: Despliegue en Railway

Suba el modelo entrenado y el dataset a Railway. El sistema estará listo para usar en la web, permitiendo:

  • Visualizar los clusters identificados
  • Predecir a qué cluster pertenece un nuevo vuelo
  • Consultar vuelos específicos
  • Ver estadísticas y análisis

Paso 3: Agregar Nuevos Datos

Cuando tenga nuevos datos (ej: 1,000 vuelos adicionales), simplemente súbalos desde la sección "Mantenimiento". El sistema:

  • Valida que las columnas coincidan
  • Combina los nuevos datos con el dataset existente
  • Elimina duplicados automáticamente
  • Reentrena el modelo automáticamente con todos los datos
  • Actualiza las recomendaciones y análisis

Ventaja: No necesita reentrenar manualmente. El sistema se actualiza automáticamente cada vez que agrega datos nuevos.

Paso 4: Análisis y Acción

Use las visualizaciones y recomendaciones del sistema para:

  • Identificar rutas problemáticas
  • Asignar recursos donde más se necesitan
  • Tomar decisiones operacionales informadas
  • Monitorear mejoras a lo largo del tiempo

Interpretación de los Clusters

Cada cluster representa un grupo de vuelos con características similares. El sistema proporciona:

Tipo de Cluster

  • Puntual: Vuelos con retrasos mínimos - mantener estándares
  • Retraso Moderado: Oportunidades de mejora identificadas
  • Afectado por Clima: Retrasos principalmente por factores externos
  • Alto Retraso: Requiere atención inmediata y análisis profundo

Recomendaciones Específicas

Cada cluster incluye recomendaciones personalizadas basadas en sus características. Estas recomendaciones ayudan a:

  • Priorizar acciones correctivas
  • Asignar recursos eficientemente
  • Implementar mejoras específicas
  • Prevenir problemas futuros

Impacto

El sistema también indica el impacto esperado de cada cluster en términos de:

  • Satisfacción del cliente
  • Costos operativos
  • Eficiencia operacional

Preguntas Frecuentes

¿Con qué frecuencia debo agregar nuevos datos?

Recomendamos agregar nuevos datos periódicamente (semanal o mensualmente) para mantener el modelo actualizado y reflejar cambios en las operaciones.

¿Qué pasa si las columnas de mi nuevo archivo no coinciden exactamente?

El sistema valida automáticamente las columnas y le indicará exactamente qué columnas faltan o sobran. Asegúrese de que su archivo tenga las mismas columnas que el dataset original.

¿Cuánto tiempo toma reentrenar el modelo?

El tiempo depende del tamaño de los datos, pero típicamente toma entre 2-10 minutos. El sistema le notificará cuando el reentrenamiento esté completo.

¿Puedo usar el sistema sin tener conocimientos técnicos?

Sí, la interfaz está diseñada para ser intuitiva. Solo necesita subir sus archivos CSV y el sistema se encarga del resto automáticamente.
